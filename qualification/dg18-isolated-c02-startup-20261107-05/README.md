## New prerequisite

Before preparing a native subject, bwrap_host.py requires the canonical protected
system executable /usr/bin/bwrap, the exact original PATH search order, protected
search directories, no earlier /usr/local/bin/bwrap, the /bin alias, root ownership,
nonwritable invocation/resolved ancestry, stable inode and byte digest, Ubuntu
24.04 amd64 package identity, resolved libraries, and protected helper tools. The
module executes the pinned upstream-shaped namespace probe with a 500 ms deadline.
Only exit zero with bounded capture and CLOSED cleanup is affirmative. The local
NETLINK_ROUTE refusal does not qualify, and unknown output or silence cannot
substitute for successful namespace execution.

This is deliberately stronger than the pinned upstream probe's narrow warning
classification. Native selection and successful initialize remain facts to be
observed under the original guard; this prerequisite does not claim either.

If /usr/bin/bwrap is absent, signed_distro_setup.py may run only as part of root's
fresh authorized disposable-host preparation. Its fixed authenticated HTTPS
Ubuntu noble/noble-updates/noble-security sources use the protected Ubuntu archive
keyring. It ignores inherited apt snippets, permits no unauthenticated repository,
installs exactly one previously absent version-pinned bubblewrap package, and
refuses additional installs, upgrades or removals. Four apt operations are each
bounded to 180 seconds and 1 MiB per stream; only the owned temporary apt tree is
removed. There is no system ownership/mode repair or namespace-policy change.
Cleanup tolerates only directory size/mtime/ctime movement caused by the package
write; executable bytes, inode, owner, mode, symlink and ancestry identity remain
bound. The startup binding has no such metadata exception.

### Actual transaction gate (startup04r2)

The simulated transaction is retained as a diagnostic check. The install command
now has its own APT V3 Pre-Install-Pkgs hook. A nonzero hook exit stops APT before
dpkg mutation. The hook requires exactly the actual bubblewrap unpack and
configure actions for the pinned version and amd64, with no additional package
actions. It also compares the complete clean dpkg package prestate with the state
captured before simulation. It queries the kernel's frontend lock owner and
requires that owner to be the exact bound root apt-get ancestor, with the same
binary, argv and process start time. The inner backend lock is deliberately not
claimed: APT releases that lock before invoking its package manager and retains
the frontend lock. No lock is acquired, released or bypassed by this helper.

The helper executes from bytes checked against the entry-bound digest. The
request, fixed source/config inputs, root-owned tool bytes and existing dpkg
configuration are rechecked. Ubuntu apt and libapt-pkg6.0t64 must both be exactly
2.8.3 or exactly 2.8.4ubuntu0.1. Those Ubuntu source versions were examined
separately from upstream 2.8.2; an actual host/package observation is still needed.
Existing dpkg configuration must contain only comments, the default log option
and no-debsig; unsupported options cause refusal, not configuration repair.

A Post-Invoke hook under the same apt frontend lock records the actual package
state difference. It requires one new installed bubblewrap at the pinned version
and every previous package record unchanged. Preparation joins the exclusive
root-owned before/after receipts, then rechecks current state. The reported
install count comes from that actual difference. A successful exit, printed apt
summary or simulation cannot substitute for these receipts. Raw package inventory
and command output remain private; the public setup summary carries digests and
the bounded effect list.

Each hook has a 10-second ceiling inside the existing install command's
180-second ceiling. No extra apt transaction, native allocation, hold extension
or provider operation is added. Unsupported host preconditions, any missing
receipt, any unexpected actual effect or unknown cleanup refuse preparation.
This is an engineering candidate for independent review; no actual signed package
transaction or native startup is established by the inert author controls.
