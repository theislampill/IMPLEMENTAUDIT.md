### Exact predicate capture

The only existing bwrap function with a source-body change is protected_chain.
It adds loop position labels and captures the operands in the original boolean
expression. Erasing those capture bindings reproduces the original predicate:

```python
not st.st_mode & 0o022 and not os.access(node, os.W_OK, effective_ids=True)
```

The original order and short circuit remain: the mode mask is evaluated once;
os.access is evaluated once only when that mask is zero. No permission, stat,
readlink, path-resolution or other host query is added or repeated. The same
original Refusal is raised. Only after that refusal occurs does a bounded helper
attach closed scalar metadata to that exception. An observer failure is ignored
without replacing the original failure. Successful guard behavior and return
values are unchanged. All other bwrap function bodies, the full signed setup and
actual APT transaction guard, and all original14 candidate/support files retain
their exact bytes or source bodies.

The capsule contains fixed public invocation/node roles, INVOCATION or RESOLVED
ancestry, a zero-based index from the leaf, the chain's maximum ancestor index,
SAME or DIFFERENT resolution relation, and the actual evaluated mode/access
operands. Index 0 denotes the leaf; index==depth denotes root. Positions are
bounded to 0..64. Fixed public path roles are comparison labels only. Unlisted
system nodes/targets use a closed UNLISTED role and exact chain position; their
runtime path is never published. The public callsite is selected from the exact
reviewed source codebook and must match an observed public frame. A literal
keyring callsite must match the UBUNTU_ARCHIVE_KEYRING invocation role.

| Captured condition | Closed failure observation |
| --- | --- |
| Nonzero mode mask 2, 16 or 18 | Group/other write flags and mode_nonwritable=false; effective_write_access=NOT_EVALUATED |
| Zero mode mask and effective W_OK true | Both write bits false; mode_nonwritable=true; effective_write_access=true |

The access_mode=W_OK and effective_ids=true fields describe the fixed source call
arguments. NOT_EVALUATED explicitly means that call did not run. No whole mode,
