S³E combines the Evolved-LAW, Evolved-SSD, Evolved-DRF and Evolved-CSS property families through existing native owners. It keeps decision-relevant state, current authority, evaluator fitness, effect evidence, consequence and recovery coherent without asking a user to select a lineage.

The individual lineage pages explain each contribution. The three new family syntheses preserve overlap and tension; one invariant still has one native implementation owner.
