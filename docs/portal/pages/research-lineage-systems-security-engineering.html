Systems Security Engineering

Use this lineage when authority, trust, adverse action or protected consequences can change whether an otherwise valid operation is acceptable.

What this lineage contributes

Systems Security Engineering starts with a protected consequence and a bounded adversary or threat model. It makes trust boundaries, least privilege, current authorisation, secure failure and recovery explicit, while keeping a command’s apparent success distinct from the intended world effect.

The lineage also contributes analysable mechanisms: minimise authority and shared mechanisms, mediate consequential actions at the current boundary, and keep capability separate from permission.

What changed

The landed v0.4.0 composition binds governed mutation to the current controller and current authority state. Cooperating writers use one checked custody boundary, and stale controller claims refuse before product or transaction effects.

External mutation and closure paths now require explicit authorisation, structured readback and current interface identity. This is bounded control of the repository’s own governed paths, not a host-wide security perimeter.

What was already native

IMPLEMENTAUDIT already treated repository text as data rather than mutation authority, required explicit scope for destructive work, preserved STOP states, and separated local validation from external effect evidence. Existing owner checks already covered many trust and authority properties.

What was rejected

No security mode, universal threat worksheet, attacker simulation requirement, trust score or extra audit object was adopted. A fixed “two-person” rule and ceremony-only approval are insufficient where the actual authority and capability are absent.

What remains unverified

This route does not claim security certification, complete mediation outside governed helpers, resistance to a privileged same-principal process, supply-chain provenance or universal host isolation. Non-cooperating writers and external systems remain outside the exact tested fence unless independently proved.
