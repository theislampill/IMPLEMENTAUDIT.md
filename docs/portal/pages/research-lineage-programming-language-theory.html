Representation and semantics

Full-input admission differs from accepting a prefix or recovering an editing structure. Capture avoidance differs from current name resolution. Type soundness is scoped to a calculus and trusted boundary, rather than absence of every bad outcome. Effects can expose possible actions without granting authority.

The C0310 correction

A successful safeguard does not make its safety obligation inapplicable. Applicability fixes the semantic operation, contract, validation unit and governed effect projection first. For each unit, invalidity must imply no released effect attributable to it. Validation before commit or justified isolation/rollback can satisfy that implication.

Unit boundaries change the result

With two frames, committing a valid first frame is allowed when each frame is a validation unit. The same release violates a contract treating the pair as one invalid atomic message after the second frame fails. Whole-message buffering satisfies that changed finite model; the result does not demand buffering every unbounded stream.

Composition remains guarded

A continuation that captures a linear resource can duplicate its use if resumed twice. One compatible discipline must relate value linearity, effects and control flow; three individually favorable labels do not establish it. One-shot fragments can be adequate, but one-shot alone does not prove eventual resumption or progress.

A supported example and its conditions

An always-reject service can satisfy the finite safety implication while providing no useful service. A genuine effectless operation or permissive contract is a nontrigger; an unknown operation or missing attribution remains unknown. A real in-scope invalid-unit release can refute the claim even when positive coverage is incomplete.
