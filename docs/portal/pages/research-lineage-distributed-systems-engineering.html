Distributed Systems Engineering

Use this lineage when custody, observation or effects cross a process, worktree, host, API or publication boundary.

What this lineage contributes

Distributed Systems Engineering contributes explicit partial failure, unknown outcome, causal ordering, currentness, configuration, recovery and fenced effects. A request, receipt, command exit or local green result is not the remote effect; each evidence leg keeps its own identity and observation boundary.

Effects are fenced to a current controller and current interface where the repository controls cooperating writers. Retry and takeover decisions must distinguish not started, pending, committed, completed, failed, degraded and reverted states when those states matter.

What changed

The landed v0.4.0 composition sharpens controller custody, verification windows and receiver-current readback. Stale claims refuse before governed mutation, and asynchronous effects remain nonterminal until independent observation resolves the intended world state.

Release identity also uses exact commit and tag relationships rather than assuming that equal trees or matching version text prove the same release event.

What was already native

IMPLEMENTAUDIT already compared repositories and external state explicitly, preserved pending effects, required fresh readback after mutation, and kept local source evidence separate from hosted and publication evidence. Many distributed properties therefore mapped to existing native owners.

What was rejected

No distributed runtime, consensus layer, universal retry loop, quorum ceremony or mandatory fanout was added. A shared issue, branch, milestone, package or public surface is not itself a dependency. Ordinary local reversible work retains its direct path.

What remains unverified

This route does not claim consensus, linearizability, fault tolerance, arbitrary-process exclusion, exactly-once effects or universal distributed safety. The tested fence covers named cooperating repository writers; external services and non-cooperating same-principal writers need separate evidence.
