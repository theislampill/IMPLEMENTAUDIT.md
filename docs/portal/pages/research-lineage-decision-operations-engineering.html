Decision & Operations Engineering

Use this lineage to select the least costly action that can still change a named decision or protect a real consequence.

What this lineage contributes

Decision & Operations Engineering names the decision owner, consumer, deadline and action authority before selecting a model. It preserves meaningful alternatives, distinguishes hard constraints from preferences, resists proxy substitution, and keeps reversibility and option value visible.

A cheap authoritative discriminator takes precedence when it settles the decision. More analysis is justified only while its expected information value exceeds cost and a capable consumer can still act.

What changed

The landed v0.4.0 composition unifies proportionality, ready-frontier scheduling and consequence-aware intervention in existing action-selection owners. Work fans out only when independent cells, capacity and expected value justify it; shared writes serialise without forcing unrelated cells to wait.

Consequential action now accounts for current target state, feedback, containment, recovery and the intervention chain’s actual capability. Low-consequence reversible work with direct readback remains serial.

What was already native

IMPLEMENTAUDIT already required a live consumer, explicit acceptance, bounded phases, alternatives after failed hypotheses and STOP when evidence could not support the next action. The crosswalk found many decision properties already stronger in native controls.

What was rejected

No optimisation oracle, mandatory scoring matrix, fixed fanout target, numerical value threshold or planning ceremony was adopted. Process volume, reviewer count and utilisation are not value evidence. A shared issue or milestone does not by itself create a dependency.

What remains unverified

This route does not prove globally optimal decisions, calibrated utility, complete stakeholder representation or universal scheduling gains. It establishes bounded action-selection contracts and deterministic cases in this repository; other environments require their own observations.
