## Controls

### Positive

- a changed evidence/state input recomputes the correct dependency frontier;
- independent READY lanes run while shared writers serialize;
- JOIN is required before dependent conclusion;
- unresolved obligations prevent unsupported terminal closure;
- re-entry reconstructs the same actionable frontier from authoritative
  evidence plus compact projection/selective retrieval.

### Negative

- a stale static plan cannot override current evidence;
- omitted obligation cannot disappear during compaction;
- child skill or agent cannot establish READY/JOIN/currentness/closure;
- same-owner writers cannot run concurrently;
- changed candidate cannot consume stale qualification;
- trivial work does not materialize heavy orchestration.

### Boundary

- one-step versus multi-dependency work;
- advisory plan divergence versus consequential currentness mismatch;
- temporary blocked lane versus unresolved terminal obligation;
- local child-agent result versus joined global conclusion;
- reference-only cognition versus mechanical derivation.

### Adjacent

- R51 progressive cognition without DAG authority;
- R53 scheduling without agent-lane semantics;
- R54 lane execution without graph authority;
- R55 nested loops without duplicate orchestration owner;
- R42 cognition/authority separation without a second state machine.

### Held-out

Use H14, H15, H16, H18, H19 and H20 from
`V0410_HELD_OUT_ACCEPTANCE_PLAN.md`, plus one unseen multi-lane recovery fixture.
