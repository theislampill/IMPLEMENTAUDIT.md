## Custody and reproduction

`SOURCE_LOCK.json` identifies the exact input archives and their members.
`PROPERTY_INDEX.json` retains property identity, criterion, trigger, inherited
status and a digest-bound pointer to the full source row. `RELATION_INDEX.jsonl`
retains every directional relation identity and its endpoints. Neither index
establishes empirical truth, independence, adoption or implementation coverage.

Run `python build_intake.py --packets DIRECTORY --output OUTPUT_DIRECTORY` to
rebuild these navigation projections. DIRECTORY must contain the three exact
`EVOLVED_SSS_FROZEN_PACKET.zip`, `EVOLVED_BWP_FROZEN_PACKET.zip` and
`EVOLVED_AMA_FROZEN_PACKET.zip` files. The builder verifies raw archive identities
and embedded member inventories before consuming records. It does not execute
code from the archives or extract members to the filesystem.

Source-row digests use UTF-8 JSON with sorted keys, compact separators and
unescaped Unicode. They identify that canonical serialization, not a substring
of the original JSON file. Member digests identify original member bytes.

With the complete repository checkout and this directory's JSON/JSONL files
present at `docs/research/implementaudit/triad-integration`, run
`python validate_research.py` from this directory for population, protected-field, endpoint,
frontier and source-postimage consistency. Run `python analytical_cases.py` for
the finite examples. Use the intake builder's `--check` option to compare the
four generated navigation indexes without writing. Passing these checks does
not establish semantic acceptance or release readiness.
These two checks use the checked-in files and need no source archives. Rebuilding
or checking the navigation indexes additionally requires the three exact archives.

The published indexes are project-authored navigation and normalization over
the supplied analytical packets. External papers, standards and upstream source
archives are not redistributed here, and no upstream license is changed.
Full source semantics, assumptions, access limits and bibliographic references
remain at the digest-bound locators. Source reuse does not create independent
corroboration. No runtime payload depends on these research files.
