## Native concepts and within-tradition synthesis

The native production relationship links warranted family scope, commonality and variability, reusable core assets, domain and application engineering, configuration and derivation. It becomes an operative system through product feedback, scoped assurance, shared-change decisions and lifecycle economics. Features, assets, configuration values, modules and runtime capabilities are related but not identical. Domain and application responsibilities can coexist in the same people and iterate concurrently.

The strongest core is conditional: justify the family; maintain meaningful variation; realise identified products; separate encoded consistency, realisation and behavioural evidence; preserve or explicitly migrate supported obligations; and retain adequate alternatives. Runtime variation adds transition/control obligations. A small static family may use a table, ordinary modules and a reliable manual production instruction. No mechanism is retained merely because it would make the system more elaborate.
