## Composition is an investigation of interactions

**Trifecta synthesis = A × B × C, under explicit guards and applicable contexts.** This is conceptual notation, not a literal product or an assertion that every combination is scientifically meaningful. The accepted result is the actual composition model, including justified nonrelationships, rejected novelty, constraints, counterexamples, alternatives and unresolved claims.

For each family, keep the independently established constituent content, supported direction, receiving use, shared premise and joint effect distinct. A partial contribution need not prove the receiver’s whole predicate to be useful. Conversely, a partial relationship cannot establish whole-system effectiveness, implementation or authority. Each family retains its own predicates; this index imposes no universal scientific taxonomy.

## Five identity layers

1. **Original source record:** frozen historical delivered bodies and their original identities.
2. **Corrected scientific subject:** an exact later study and its bounded independent reviews.
3. **Publication projection:** the public-safe explanation, with explicitly limited source access.
4. **Repository target decision:** an actual owner’s context-specific disposition or receiving action.
5. **Implemented behavior:** exact native code, execution and acceptance evidence, where separately qualified.

No layer automatically establishes the next. Operational transfers between scientific cohorts change custody, not family membership or historical identity.
