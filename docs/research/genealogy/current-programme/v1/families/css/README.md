This package connects the three CSS lineage histories, their public property readers, the separately accepted CSS-S identity, guarded family composition, Pages and four rough owner-linked research outlines. **It is not a whole-family completion certificate.** The detailed corrected scientific interpretation is prepared privately; source-specific disclosure and actual desktop/mobile visual acceptance remain separate requirements. CSS brings together three questions about consequential decisions. Cognitive Systems Engineering asks how the people, agents, tools and representations doing the work can maintain useful state, coordinate and intervene. Statistical Engineering asks what an observation means, which states it can distinguish and how uncertainty or dependence limits the inference. Systems Safety asks which loss or hazardous state matters, which constraint can control it and how the achieved state and recovery will be confirmed. Their common concern is decision-usable, consequence-aware state. Their predicates remain different: a clear display does not validate its measurement, and a valid measurement does not confer authority or establish containment. [Historical family explanation][css-page]

The synthesis reuses their 195-member union; it does not contribute another 195 independent properties. The current programme identifies its later scientific subjects and qualifications separately. ## The composition question

For a particular decision, cognitive receiving must concern the state that the observation actually discriminates, and the available action must respect the consequence-specific control boundary. A common consumer, relevant time, configuration and supported interface relation make a joint claim assessable. An independently useful contribution from one lane can remain partial; a qualified constituent does not supply every other lane's predicate. The detailed [synthesis explanation](CSS-S.md) distinguishes an illustrative public account from the separately accepted current study.

## Scientific and engineering acceptance

The three current constituent subjects are selected at the captured Cohort A boundary. CSS-S has its own accepted scientific subject, qualification receipt and two accepted reviews. The independently refreshed central receiving record preserves staged intent and does not establish applied central selection. Scientific qualification, central application, documentary receiving, public branch publication, Pages deployment and native implementation remain separate states.

Their source and fixture evidence does not establish current runtime activation, performance or complete synthesis adoption. The four rough outlines preserve this ownership and the active campaign's acceptance boundaries; they create no new issue or implementation mandate.

## What public disclosure would add

The private counterpart contains the corrected lineage narratives and property catalogue, exact current synthesis interpretation and finding maps, and proposed derived explanatory text for source-specific disclosure. A public decision must cover those exact sections and their source limits; an archive hash or scientific acceptance alone is not permission. Until then, this public package explicitly leaves detailed current properties, directional and higher-order results, counterexamples, alternatives and novelty disposition outside its public-complete scope. No missing historical original is replaced with the newer neutral study.
