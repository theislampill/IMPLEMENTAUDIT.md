# SPR-S — twenty research questions and answers

[Coherent synthesis](SPR-S.md) · [Source identities](SOURCES.md#spr-s)

This is the complete prepared current answer map derived from the accepted report. Its partial, negative and unresolved consequences are retained.

| Question | Current answer and consequence |
|---|---|
| Q01 — Description, interpretation, adoption and acceptance | An observation, semantic interpretation, adopted requirement and accepting decision have different warrants. A useful source statement can enter an interpretation before adoption is settled. No universal four-stage bureaucracy is imposed. |
| Q02 — Abstraction and nonuniqueness | The receiving query determines the distinctions that must survive. Nonunique models can be adequate for one query; a collision that merges different query answers defeats that query’s recovery. C0221 supplies known nominal stage/type fields before RT03 can decide preservation. |
| Q03 — Syntax, relations and branch selection | Parsing, a relational constraint and selection of a branch are distinct. An implicit relation need not have a unique output or require a universal syntax tree. |
| Q04 — Symbols, units and world correspondence | An exact symbol manipulation still needs the actual interpretation and units for a claim about another object. The symbol-to-world map is not supplied by syntactic validity. |
| Q05 — Learning, synthesis, oracles and acceptance | A generator, a learner, a finite checker and an acceptance decision have different roles. Adequate finite evidence remains useful at its domain; agreement with a weak oracle does not prove intent. |
| Q06 — Uncertainty and guarantees | Joint, marginal, qualitative and structured guarantees remain distinct. A confidence scalar cannot silently replace native uncertainty or a simultaneous guarantee. |
| Q07 — Satisfiability and causal strategy | A satisfying trace can exist without an implementable strategy under the permitted information order. The early/late observation control demonstrates the difference. |
| Q08 — Model certificates and external transfer | A nonempty model set and a common mathematical decision can support a model-relative certificate. Applying it externally needs its own inclusion, noise and realization premises; missing external evidence does not invalidate the pure model theorem. |
| Q09 — Compositional guarantees | Local claims compose only through the actual compatible endpoints, contexts and linking premises. C0221’s separately known nominal type/use fields are a real partial RT03 input; the map and whole correspondence remain unknown and the reverse is independently bounded. |
| Q10 — Resources, safety and progress | Resource conservation or safe finite prefixes do not establish liveness. Fairness, time horizon, environment and delivery assumptions remain explicit. |
| Q11 — Selective change and reuse | Reassessment follows the actual changed dependency. A new date does not by itself invalidate a claim, and unchanged bytes do not guarantee validity for a new consumer. |
| Q12 — Information and permission | An informative experiment can be inadmissible. Excluding it does not authorize another action. Pure mathematical reasoning does not acquire an invented external-action gate. |
| Q13 — Circular evidence | A round trip or copied-back reference can preserve the same mistake. A target query needs an independently warranted reference when that independence is part of the claim. |
| Q14 — Constraints, penalties and policy | A finite penalty is not a hard constraint; feasibility and nondominance do not choose a policy. Exact optimization also leaves model and input adequacy open. |
| Q15 — Goal, task, grant, obligation and evidence | These objects and their relations remain distinct. The neutral model exposes their interfaces without designing a private target or assigning it authority. |
| Q16 — Views, versions and disputes | Partial views and disagreements can be retained. A merged display is not consensus, and recency alone is not adoption. Joint consistency is needed for an asserted joint guarantee. |
| Q17 — AI assistance and source transfer | A benchmark, generated artifact, model comparison or historical replacement study supports only its actual task and role. C0221’s adaptive-consistency description is not an AI comparison; its partial transformation input proves neither assurance nor workflow benefit. |
| Q18 — Higher-order compatibility | Pairwise compatibility can coexist with an empty joint feasible set. A common bearer and a common witness are required for the whole claim; the general principle is already inherited rather than newly discovered here. |
| Q19 — Privacy and information order | Observer, purpose, retention, correlation and actual effect matter. A local data-flow view may drop the relevant inference relation; a new-read revocation need not remove already cached information. |
| Q20 — Cheaper alternatives and no change | Choose an adequate configuration for the actual task and claimed burden. A direct check, smaller view, no additional artifact or no change can be warranted; comparative savings are not measured by this synthesis. |
