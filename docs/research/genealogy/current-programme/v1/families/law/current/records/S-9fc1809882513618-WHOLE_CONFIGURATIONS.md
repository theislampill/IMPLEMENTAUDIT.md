Unknown cost or benefit stays unknown; a useful partial input can still be identified without a complete total estimate.

The selected configuration can be smaller than the union of three method catalogues. Removing an artifact while preserving its function can improve the package. Removing a required function while keeping the artifact's name cannot. Keeping the existing adequate arrangement is an affirmative alternative, not a failure to synthesize.
