## Every property retains its actual prepared route

[OWNER_MAP.json](OWNER_MAP.json) contains **278 separate routes** extracted from the already-public prepared target records. Each identifies the source file/hash/pointer; original disposition; prepared absorption; actual native product carriers and operative source references; concern and primary-decision routing; and the separate documentary receiver/residual. No property was routed merely by copying the six shared family owners into every row.

The old prepared record's “required delta” or residual is a historical conditional consideration, not proof that the current runtime lacks it. Some frozen owner references no longer exist at a later source baseline. Their absence is not repaired by renaming another path as the same historical owner. The public native record already distinguishes those layers and the map preserves the full caveat. Later native work must reread actual current source and package/host evidence, determine whether the trigger still holds, and retain adequate/no-change, conditional, rejected, research-only or nontriggered outcomes as warranted.

The issue closure state does not settle every scientific mechanism or future claim. Likewise, a newly accepted scientific interpretation does not reopen the issue. This commission makes no issues or RLGWOs, performs no runtime/package change, transfers no other owner's tree and grants no merge or deployment. The 32-slot programme remains a conceptual responsibility map.
