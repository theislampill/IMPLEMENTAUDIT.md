# DG10 native Stop receiving

DG10's finite native predicate was accepted after an actual Codex desktop
false-completion refusal, a second refusal with `stop_hook_active=true`, and a
truthful current nonterminal yield followed by native TaskComplete. Independent
receiving checked the real event, response, validator result, continuation and
pending obligations. The parent remained open. This does not close R0037,
establish formal native L4 or handoff, or authorize mainline adoption.

The opt-in `host-stop-interlock.py --codex-stop-policy <policy> <sha256>` entry
is for an explicitly selected task qualification. It requires the host's own
trust review of the exact command, captured source and policy. It does not
enable hooks, change global settings, create credentials or treat its own JSON
receipt as authenticated host evidence. Native stdout uses only Codex's Stop
control fields; detailed ingress and results remain in private task custody.

The policy selects an exact parent, existing H0 store and qualified Windows
binding owner, validator, and private evidence location. The repository-only
native-runtime composition remains separately selected and materialized under
`source-peers/README.md`; it is not silently replaced by the portable H0 owner
or claimed as native plugin installation. The existing Windows custody owner
holds validator bytes against replacement while Git Bash executes them.

The Windows disposition consumer now selects Git Bash explicitly and transfers
Windows paths correctly, avoiding the System32 WSL launcher and a false
self-sibling refusal. Legacy wrapped calls to `main()` remain compatible; the
new policy invocation alone has its explicit argument contract.

Historical native profiles, failures and protected UNKNOWN episodes remain
unchanged. New exact current-source tuples are additive. Private native evidence
and the task-local trusted hook configuration are not public repository content.
The successfully executed qualification source remains frozen while this
publication successor receives its separate package and hosted qualification.
