## Original decision and source custody

also match the pathspec. Acquisition does not replace this behavior with an
exact-name index lookup or a predicted answer.

The established `snapshot_complete_git_inputs` owner first acquires every

Equal file bytes in another repository do not satisfy this custody relation.
The observer result is acquisition evidence; the unchanged original executes

The existing C2 restrictions remain: producer-owned physical source and Git

all possible quoted indexed output names and at most 64 KiB stderr; unknown
statuses or larger streams refuse. No public resource knob or new executor is
