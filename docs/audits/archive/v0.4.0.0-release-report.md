## Package architecture and frozen identity

The release architecture is one atomic, version-coherent dual-host plugin
package. `IMPLEMENTAUDIT.plugin.zip` is its canonical generated artifact. Equal
`.codex-plugin/plugin.json` and `.claude-plugin/plugin.json` manifests route the
same `./skills/` tree. `/implementaudit` remains the sole stable public/default
governor. The atomic population contains one public/default governor and four
child skills: `audit-state`, `audit-assess`, `audit-implement`, and
`audit-andon`. Every child returns bounded cognition to the governor;
`audit-andon` also supports the fenced direct cord-pull entry.

`IMPLEMENTAUDIT.skill` is the generated, checksummed flattened standalone
compatibility projection from the same source identity. It is not the canonical
plugin topology, a second independently versioned package or native host-load
evidence.
